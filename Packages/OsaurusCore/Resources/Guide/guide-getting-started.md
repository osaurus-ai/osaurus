# Getting Started with Osaurus

Osaurus is a free, open-source macOS AI app: agents, memory, tools, and identity that live on your Mac. It runs fully offline with local models, and connects to cloud providers only when you choose. MIT licensed, built in native Swift for Apple Silicon.

## Requirements

- macOS 15.5 or newer, Apple Silicon (M-series) Mac.
- Download from the GitHub releases page or `brew install --cask osaurus`.
- Docs: https://docs.osaurus.ai · Models: https://huggingface.co/OsaurusAI · Community: Discord (invite on the website/repo).

## Finding your way around

- Chat window: global hotkey (default ⌘;) or launch Osaurus from Spotlight.
- Settings… (⌘,) opens the Management window. Agents, Automations and Inbox are pinned at the top of the sidebar (Workflows lives in the main window rail); below them the groups are General (General, Chat, Vault, Osaurus ID, Privacy & Security), Sharing (Workspaces, Access, Devices), Models (Local Models, Providers, Model Defaults), Capabilities (Tools & MCP, Channels, Agent Runtimes, Web Search, Voice, Images & Video, Computer & Browser Use), Context (Memory, Knowledge, Skills) and Developer Tools (Server, Sandbox, Insights, Tasks). Commands opens from Chat; Wallet & Credits from Osaurus ID; Permissions from Privacy & Security. Type a setting name in the sidebar search to jump to it.
- CLI (install from Settings… (⌘,) → Server → Overview → Command Line Tool → Install CLI): `osaurus ui`, `osaurus serve`, `osaurus status`.

## First steps

1. Choose how Osaurus runs in the welcome window: a private model on this Mac, Osaurus Cloud, or an AI account you already have. **Start chatting right away** (Osaurus Cloud) needs nothing downloaded, and you can change it any time in Settings… (⌘,) → Local Models or Providers.
2. In the first chat, pick a teammate and try one of its tasks, or type your own. Osaurus asks for each permission (Calendar, Mail, Downloads) only when a teammate needs it.
3. Open **Set Up Osaurus** to see what is left. It sits under a new chat's greeting as **Set Up Osaurus: N left** until nothing is left, with **Skip setup** beside it to stop suggesting setup in new chats, and is in the Osaurus menu and Settings → Chat → Behavior. What is left can include trying and turning on a workflow, more folders for Keeper, your chat history, memory, tool servers, chat apps, a phone, and more.
4. Ask the Orchestrator anything about Osaurus. It can change settings for you (download models, add providers, switch defaults) and answer questions about any feature. Create your own agents in Agents for other work.

## Your team, the first run, and discovery

- **The team.** A fresh install gets a small team of agents, each bound to one app or folder: **Planner** (Calendar and Reminders), **Courier** (Mail), **Keeper** (the Downloads folder, read only, and Notes), **Scout** (the web), and on a Mac with Xcode, the command line tools, or a git configuration, **Builder** (one project folder). They appear in Agents like any other agent, and you can rename them. Seven default workflows (Morning Brief, Meeting Prep, Mail Triage, New Download, End of Day, Research Brief, and Repo Digest with Builder) are installed with no schedule. Existing installs get nothing on update; **Create starter agents** makes the same team. An organization's installer (an Osaurus bundle) may leave out some or all of the team when its own agents do the same jobs, along with the workflows that use them, and may skip the welcome step and the walkthrough.
- **The welcome window.** A fresh install opens a small window over a landscape that matches the time of day, where the Osaurus dino says good morning (or afternoon, or evening). **Get started** accepts the Terms and Privacy Policy; **Share anonymous usage data** below it is an optional switch, on by default, that never includes your chats, prompts, files, or keys (Settings → Privacy & Security → Data Collection changes it later). Next, Osaurus asks **What matters most to you?** with three choices: **Keep it private, on this Mac** (recommended, with a green glow; downloads Raptor 0.7, the Osaurus agent model, and says how it fits this Mac), **Start chatting right away** (Osaurus Cloud: nothing to download, with a free welcome credit), or **Use an AI account you already have** (sign in with ChatGPT, Grok, or OpenRouter, or use Claude Code or a key from OpenAI, Anthropic, Gemini, or any compatible endpoint). Onboarding offers only Raptor 0.7 as a local model; add others later from Settings → Local Models. Click the dino on any step ("Click me for help!") and it explains that step in a few speech bubbles, such as what a model is and why one was picked. **Skip setup** at the top right, or closing the window, does the same when no model is chosen yet, so the first chat always has a model. Skip setup also skips the first-run walkthrough: the team is still created, and the first chat opens ready for anything. If Cloud is still connecting when the chat opens, Osaurus says so and answers as soon as it is ready. When you continue, the window turns into a compact chat window. With Reduce Motion on, the windows crossfade.
- **The first run.** The first chat opens with a short message from Osaurus, typed out like any reply: where the chat runs, and that Osaurus is the one you talk to, who can change settings for you or hand a job to a teammate. Then it shows the team as a list, one row per teammate with the avatar it has in the sidebar and a line in its own words ("Work with me to plan out your day."), and Osaurus itself last. Pick one and try one of its tasks, or type your own task. Picking Osaurus offers a few things to ask it directly. Typing a teammate's job, such as "help with my mail", picks that teammate. **Skip setup** in the walkthrough's header ends setup at any step, and so does typing "skip". Planner asks for Calendar and Reminders together. If macOS does not allow Downloads, Keeper offers **Try Again** and a button that opens System Settings at Files & Folders. Opening Keeper later, before Downloads was allowed, asks **Allow Downloads** in place. The model starts loading while you read. After a task's answer, setup offers **Meet Another Teammate**, which brings the team back to try someone else, and **Done**. The offer comes back under each of those answers until you pick **Done**, use **Skip setup**, or type a message of your own. The sidebar stays closed during setup so the walkthrough has the window; it opens again when setup ends, and the sidebar button brings it back any time. Anything typed that is not about the walkthrough itself, a task or a question about Osaurus, ends setup and goes to the Orchestrator with your exact words. Setup ends with the first result. A relaunch during setup reopens the same chat at the same step. Setup never starts on its own a second time.
- **Discovery.** After the first run, a new chat can show one card under the greeting with something you have not tried yet, such as trying a default workflow and then turning it on, giving Keeper another folder, bringing your chat history, reviewing memory, connecting a tool server (MCP) or a chat app such as Telegram or Slack, adding a skill or plugin, giving the Orchestrator a working folder, turning on Computer Use or Browser Use, connecting Messages to Courier, or pairing a phone. **Try a Default Workflow** runs one you have not run yet, starting with your first teammate's; when it completes, the same chat offers to turn it on. At most one new card shows per day, and never during a task. Tap the card for a short walkthrough of one or two steps, or dismiss it to retire it for good. Doing the thing some other way retires it too. A discovery that adds an app (People for Contacts, Navigator for Maps, Shortcuts, Music) creates a new teammate rather than adding the app to an existing one; Messages is the exception and joins Courier. Every change still shows its approval card first.
- **Settings.** Settings → Chat → Behavior → **Show Discovery Cards** turns the cards off, and **Skip setup** beside the link under a new chat's greeting does the same in one click, with **Undo** in the notice that follows. **Set Up Osaurus** (in the same section, the Osaurus menu, and the link under a new chat's greeting) lists what is left to set up. The link shows only while discovery cards are on.

## The default Osaurus assistant

The built-in "Osaurus" agent in chat is the front door for setup: ask it "what's configured?", "download a model", "add a provider", "change a setting", or any "how does X work?" question. For tasks beyond configuring Osaurus (coding, web research, file work), it will offer to create or switch to a fitting agent.

## Where data lives

Everything is stored locally under `~/.osaurus/` (chats, memory, agents, config). Local models live in `~/MLXModels` by default. Nothing leaves your Mac unless you connect a cloud provider or enable network exposure.
