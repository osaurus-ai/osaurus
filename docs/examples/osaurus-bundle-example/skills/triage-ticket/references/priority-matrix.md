# Acme priority matrix

| Priority | When |
| --- | --- |
| P1 | Production is down, or data is lost or exposed, for any paying customer. |
| P2 | A core workflow is broken and there is no workaround. |
| P3 | Something is broken but a workaround exists, or one user is affected. |
| P4 | Questions, feature requests, cosmetic issues. |
